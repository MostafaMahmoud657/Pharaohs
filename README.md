# رحلة الفراعنة – Pharaohs’ Quest (دليل رفع الموقع على دومين)

الموقع **ملف واحد فقط: `index.html`** (كل الصور والشعارات والتصميم والكود بداخله).
لا يحتاج قاعدة بيانات ولا سيرفر خاص، فقط استضافة ملفات عادية (Static Hosting).

## أسهل الطرق

### 1) Netlify (سحب وإفلات، مجاني)
1. ادخل على netlify.com وسجّل حسابًا.
2. من Sites اختر Add new site ثم Deploy manually.
3. اسحب مجلد `site` (أو ملف index.html) وسيعطيك رابطًا فوريًا.
4. لربط دومينك: Domain settings ثم Add a domain.

### 2) Cloudflare Pages أو GitHub Pages (مجاني)
- ارفع `index.html` في مستودع (Repository) ثم فعّل Pages من الإعدادات.
- ثم أضف الدومين من إعدادات Custom domain.

### 3) استضافة عادية (cPanel)
1. ادخل لوحة التحكم ثم File Manager ثم مجلد `public_html`.
2. ارفع `index.html` داخله، وإن كان فيه ملف index قديم فاحذفه أو غيّر اسمه.
3. افتح دومينك للتجربة.

## ربط الدومين (DNS)
- **دومين رئيسي (example.com):** سجل A يشير إلى IP الاستضافة (أو حسب تعليمات Netlify/Cloudflare).
- **دومين فرعي (quest.example.com):** سجل CNAME يشير إلى العنوان الذي تعطيه المنصة.
- فعّل **HTTPS** (شهادة SSL مجانية في المنصات أعلاه)، وهو **ضروري** لعمل الكاميرا وزر المشاركة على الموبايل.
- قد يستغرق انتشار الـ DNS من دقائق إلى 24 ساعة.

## ملاحظات قبل النشر العام
- **الصور:** صور الملوك الثلاث تحتاج بيانات المصدر والترخيص. تأكد منها وأضفها قبل النشر العلني.
- **الاسم:** اسم الباحث وجهة العمل في آخر الصفحة الترحيبية (ابحث عنه داخل الملف عبر `t("by")` أو نصوص `by:` و`aff:`).
- **الخط:** الصفحة تحمّل خطّي Cairo وMarcellus من Google Fonts، فإن لم يتوفر الإنترنت تعمل بخط بديل ولا تتعطل.
- **للتعديل:** افتح `index.html` بأي محرر نصوص (VS Code أو Notepad++)، النصوص العربية والإنجليزية في أول الكود داخل `const T=`.
- النموذج تجريبي: القطع عينات، ومسح QR محاكى، وصورة المستخدم لا تُرفع ولا تُحفظ.
